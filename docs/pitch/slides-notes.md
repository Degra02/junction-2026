## Likely questions
- **"Does the map change the score?"** Not yet. It is shown as evidence on `/sources`; it enters the score only after a fit with its own ablation, so every "calibrated" number stays true. Without the VIGINUM list, the coordinated score's cross-validated AUC is 0.375 today: the map is how we close that gap.
- **"Can someone poison the map?"** Ties are facts about pages *we* fetched: a user chooses where we look, not what we find. Hosting platforms (Blogger, WordPress.com, Substack…) and IDs on more than 20 operators never create a tie; text ties built only from hard negatives: 0 strong.
- **"How does network detection go beyond published lists?"** Within an analysis we check 5-gram text reuse, synchronized timing, and shared GA/GTM/AdSense tags; across analyses, the live SQLite source map links domains over time by shared trackers, copies, and translations without using any list.
- **"Why does it sometimes abstain on the percentage?"** Comparing tone and claim corroboration requires independent coverage of the same event. Rather than guessing a number when coverage is sparse, we say why and highlight any persuasion techniques found in the text or image directly.
- **"How is the combined confidence calculated?"** Noisy-OR: $1 - (1 - p_{\text{content}})(1 - p_{\text{network}})$ over the scored dimensions, with each dimension's own probability shown right beside it and full log-odds breakdowns in the Scoring tab.
- **"What role do the LLMs play?"** Bounded structured tasks — extracting claims, reading visual context and rhetoric in memes, verifying grey-zone cross-lingual contradictions, and writing the plain-language summary. An LLM never sets raw scores, and Rust code-point checks drop any non-verbatim quote.
